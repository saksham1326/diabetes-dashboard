# 🩺 Diabetes Prediction Using Machine Learning

## 📌 Project Overview
Diabetes is a chronic disease that affects millions of people worldwide. Early detection of diabetes can help in preventing severe health complications.  
This project focuses on predicting whether a person is diabetic or not using **machine learning techniques** based on medical attributes.

The model is trained on a standard diabetes dataset and evaluates the prediction accuracy using different ML algorithms.

---

## 🎯 Objectives
- To analyze a diabetes dataset and understand key health indicators
- To build a machine learning model for diabetes prediction
- To evaluate model performance using accuracy and other metrics
- To provide a simple and efficient prediction system

---

## 📂 Dataset Description
The dataset contains medical diagnostic measurements for patients.

### Attributes Used:
- **Pregnancies** – Number of pregnancies
- **Glucose** – Plasma glucose concentration
- **BloodPressure** – Diastolic blood pressure (mm Hg)
- **SkinThickness** – Triceps skin fold thickness (mm)
- **Insulin** – 2-Hour serum insulin (mu U/ml)
- **BMI** – Body Mass Index
- **DiabetesPedigreeFunction** – Genetic risk factor
- **Age** – Age of the patient
- **Outcome** – 0 (Non-Diabetic), 1 (Diabetic)
